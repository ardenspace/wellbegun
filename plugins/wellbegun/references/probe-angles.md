# Blind-spot probe angles

wellbegin fires these probes **before closing a question bundle** — only the angles not yet covered by the conversation. They exist because the happy-path conversation systematically skips the same corners; each probe is a corner that real MVPs get burned by.

Probe depth is adaptive: if an answer looks thin, dig; if the user has clearly thought it through, one confirming sentence is enough. Do not run the catalog as a questionnaire.

## The five angles

Each entry: a prompt you can ask verbatim, and the bundles (1–7, see wellbegin) where it usually applies.

1. **Empty first screen** — *"What does the very first user see before any data exists?"*
   Applies to: bundle 2 (core journey), bundle 6 (product character).

2. **Day one without data** — *"Is the core journey still meaningful with zero history — or does the product only get good after a week of use?"*
   Applies to: bundle 2 (core journey), bundle 3 (success criteria).

3. **Leave and return** — *"A user disappears for two weeks and comes back. What state greets them?"*
   Applies to: bundle 2 (core journey), bundle 3 (success criteria).

4. **Unintended use** — *"What is the most likely off-label use of this, and does it break anything expensive?"*
   Applies to: bundle 1 (whose problem), bundle 5 (expensive product decisions).

5. **The receiving end of sharing** — *"If anything is shared or exported, what does the recipient — no account, no context — actually experience?"*
   Applies to: bundle 2 (core journey), bundle 5 (expensive product decisions).

## Usage rule

- Before closing a bundle, check its status table row: which of the applicable angles are still uncovered?
- Fire the uncovered ones. Record the outcome (covered / consciously skipped) in the status table.
- Only an explicit user "move on" closes a bundle with uncovered angles — and that skip is recorded, not silently forgotten.
