# wellbegun 0.7.3 — Deferred findings and commit timing

Fixes found in the first adopted cycle (an Expo app moved over from another
planning tool). Plans and state files behave as before; the runtime is unchanged.

- Outside-contract findings now persist. wellrun adds each one that is neither
  fixed nor dismissed to `.wellbegun/deferred.md`; schema 2 `run.md` is derived
  and could not hold the `## Deferred` section, so these findings were lost after
  the run report. wellnext reads `deferred.md` at triage and archives it with the
  cycle. Legacy cycles may keep `run.md`'s `## Deferred`.
- wellrun reads the project's commit rules (documents `begin.md` lists under
  `conventions`, CLAUDE.md/AGENTS.md, or a contributing guide) before the first
  record. With no stated policy it commits each record's owned changes once the
  record is verified. It never pushes without authority.
- wellnext adopt records `conventions: [<paths>]` in `begin.md` for the existing
  working-convention documents.
